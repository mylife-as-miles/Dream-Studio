# Dream Studio Gemma 4 Promo Design

## Style Prompt

A cinematic AI-native game studio promo for the Gemma 4 Good Hackathon. The visual language should feel like a premium browser game editor at night: deep space-black canvas, violet glass UI, cyan tool feedback, warm orange game-world highlights, and high-contrast typography. The story is not generic SaaS; it is creative access: players and non-builders with game ideas finally getting a practical path from imagination to playable worlds because Gemma 4 can reason, call tools, inspect screenshots, and help iterate inside Dream Studio.

## Colors

- Background: `#02030a`, `#050816`, `#070b1d`
- Primary text: `#f8f8ff`
- Muted text: `#cfd6f3`
- Gemma/Dream violet: `#9b6cff`, `#6d3df2`, `#b692ff`
- Verification cyan: `#5fe8dc`, `#8cffbd`
- World/game warmth: `#d88b42`, `#fff3d0`

## Typography

- Display and body: `Space Grotesk`
- Technical labels and tool readouts: `JetBrains Mono`
- Headline weight should be heavy and compact; body text should be large enough for video.

## Motion

- High-energy but readable product promo.
- Use zoom-through, light sweep, and panel-slide transitions.
- UI cards should slide, scale, and snap like editor panels.
- Tool chips and code lines should stagger in quickly.
- The hero screenshot should feel inspected by Gemma 4: crop, scan ring, screenshot frame, and tool-call overlays.

## What NOT To Do

- Do not make the video feel like a school-only education app.
- Do not make Dream Studio sound like it improves Gemma 4; Gemma 4 is the model helping solve the creation-access problem.
- Do not use generic blue SaaS styling.
- Do not overclaim offline/local inference.
- Do not use stock game footage; use the actual Dream Studio visual language.
